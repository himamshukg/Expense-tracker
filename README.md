# Expense Tracker 💰

A simple command-line Expense Tracker built with Python.

## Features

* Add expenses
* View all expenses
* Calculate total expenses
* Delete expenses
* Save expenses to a file
* Load saved expenses when the program starts
* Basic input validation and error handling

## Technologies Used

* Python
* File Handling
* Lists
* Dictionaries
* Functions
* Exception Handling

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run:

```bash
python main.py
```

## Data Storage

Expenses are stored in `expenses.txt`, allowing the data to remain available even after the program is closed.
